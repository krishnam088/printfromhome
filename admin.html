❓ Help Center & Local Hardware Troubleshooter

💡 Quick Troubleshooting Manual:

  • • Printer Agent Offline: Make sure your local computer's CMD prompt is active with node agent.js and the USB cable is fully plugged into the HP printer.
  • • Double Printing Safeguard: The local agent script natively saves a text token for each print job. To re-print a deleted sheet, simply remove that order's `.txt` log from the agent directory.
  • • Customer Refund Matrix: If a print crashes or fails, you can copy the Razorpay Payment ID from the specific log entry and process the cash rollback directly from your dashboard inside the Razorpay console.
